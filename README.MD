# Application de facturation

Cette application calcule le total d'un achat.

Compilation : javac -encoding UTF-8 Facture.java
Exécution : java Facture

le nouveau scenario : 3 articles à 20 dollars donnent 60 dollars + 5 dollars frais de livraison ça donne 65$
					  On affiche aussi le nom du client avant le total
					  affiche « 3 article(s) à 20 $ ».
